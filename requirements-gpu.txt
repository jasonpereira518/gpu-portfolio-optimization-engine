# GPU stack. Requires a CUDA-capable NVIDIA GPU and the NVIDIA package index:
#
#   pip install --extra-index-url=https://pypi.nvidia.com -r requirements-gpu.txt
#
# Everything is pinned to ONE release (26.08). cuOpt's wheels depend on cuDF
# and RMM from their own release, so mixing releases (e.g. cuDF 26.6 with
# cuOpt 26.2, as this file once did) cannot install at all.
#
# cu13 wheels need an NVIDIA driver that supports CUDA 13 (R580+; `nvidia-smi`
# reports the highest CUDA version the driver supports). On an older driver,
# swap every `-cu13` / `cuda13x` below for `-cu12` / `cuda12x`.
#
# Status: pinned to the current release, not yet verified on a GPU — see
# docs/setup-wsl2.md for the bring-up sequence that verifies it.
cudf-cu13==26.8.*
cuml-cu13==26.8.*
cuopt-cu13==26.8.*
cupy-cuda13x>=13.6
